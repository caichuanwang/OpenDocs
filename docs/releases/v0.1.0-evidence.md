## Maintainer 验收

- M2 的真实 DOCX/PPTX checklist 已批准，replay 与 live 结果均满足批准基线。
- 独立 Alpha holdout 包含一份真实 DOCX 和一份真实 PPTX；两者均通过公开 SDK 入口解析，
  解析结果由 maintainer 对照源文件验收通过。
- PPTX 解析产生了非致命的图片空结果警告，表示部分嵌入图片没有获得视觉描述；原生文本和
  已返回的视觉描述仍被保留。Maintainer 接受该限制作为 Alpha 已知边界。
