# OpenDocs 0.2.0 Alpha

OpenDocs 0.2.0 adds bounded native XLSX-to-Markdown parsing while preserving the existing
synchronous and asynchronous Markdown API.

The XLSX parser preserves worksheet order and visibility state, empty sheets, merged spans,
Excel tables, saved display values, formula-cache fallback, common number/date/currency formats,
standard text objects, native chart facts, and embedded media. Optional vision enrichment can add
trend, label, relationship, and meaning descriptions for charts and images; failures are
fail-open and never replace native facts.

The parser supports `.xlsx` only. It does not recalculate formulas, fetch URLs or linked
workbooks, or promise Excel font/color/pixel-layout fidelity. Windows, live vision providers, and
private real-workbook exploration remain unverified release boundaries. This is an Alpha release;
it does not claim production readiness or a performance SLA.

See `CHANGELOG.md` and the v0.2.0 evidence file for the complete compatibility and validation
boundaries.
